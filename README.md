# Epoxy Garage Floor Prep and Coating Notes

A homeowner technical guide to preparing a residential garage concrete slab before coating, testing for sub-slab moisture, comparing epoxy and polyaspartic systems, and ventilating solvent/VOC vapors safely with US EPA, OSHA, and NIST references.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — garage concrete coating prep and safety overview: `https://ahmetalkan.github.io/epoxy-garage-floor-prep-and-coating-notes/`
- Subpage — testing slab moisture and profiling concrete before coating: `https://ahmetalkan.github.io/epoxy-garage-floor-prep-and-coating-notes/concrete-moisture-and-grinding.html`
- Subpage — comparing 100%-solids epoxy and polyaspartic coating systems: `https://ahmetalkan.github.io/epoxy-garage-floor-prep-and-coating-notes/epoxy-vs-polyaspartic-coatings.html`
- Subpage — avoiding outgassing bubbles, crack telegraphing, and peeling: `https://ahmetalkan.github.io/epoxy-garage-floor-prep-and-coating-notes/preventing-bubbling-and-peeling.html`

It cites public pages on [epoxygaragefloorlab.com](https://epoxygaragefloorlab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
